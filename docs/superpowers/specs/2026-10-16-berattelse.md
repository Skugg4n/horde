# Berättelse: riktning (utkast)

Status 2026-10-16: Ola: "på väg åt rätt håll, generellt korrekt". Inget låst om slutet.

## Kärnan
En fördröjningsstrid med evakuering som mål. Horden kommer söderifrån (E4, Nyköpingshållet) och drar norrut. Vi kan inte stoppa den, bara köpa tid så att folk hinner undan. Varje sektor: håll så länge det går, backa. En sektor som "faller" kan vara planerad reträtt, inte misslyckande.

## Ordning (preliminär)
1. E4 vid Lästringe: militär vägspärr. Håller ett tag, tystnar.
2. Hagstumosse: civila i ishallen; Hemvärnet + frivilliga tills militären kommer (Ishallen, sedan Vikingavägen).
3. Gnesta Centrum och längre norrut.
4. Final: OSÄKER. Alternativ: Mölnbo (sista pendeltåget norrut, håll bron tills tåget gått) eller flykt över sjön i Gnesta (Frösjön?). Ola har inte bestämt.

## Röster
- Försvarsmakten: förstärkningar när det går.
- Myndigheten för civilt försvar: evakueringen, Hemvärnets resurser, de civila.

## Mål per dag
Tydliga mål: köp tid, rädda folk, håll tills något händer (evakuering klar, tåget gått, båtarna ute).
